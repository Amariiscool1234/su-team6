League Finder API

Backend API Documentation

Request formatapplication/json
ArchitectureSpring Boot REST API + PostgreSQL

Leagues

Search and manage recreational leagues.

6 endpoints
GET/leaguesRetrieve every league.
GET/leagues/{id}Retrieve one league by ID.
GET/leagues/sport/{sport}Find leagues by sport.
POST/leaguesCreate a league.
PUT/leagues/{id}Update a league.
DELETE/leagues/{id}Delete a league.

DELETE/providers/{id}Delete a provider.
